# tests/ — страховочные тесты в браузере

Запуск: `python -m http.server 8000`, открыть страницу, обновить с Ctrl+F5 (не file://).

- syntax.html — все JS-файлы проекта парсятся без ошибок. Запускать после каждого шага.
- smoke.html — логика fmuse.js (частоты, сдвиги, нормализация, сравнение названий). Должна быть зелёной на текущем коде.

Если smoke.html покраснел после правки логики, сначала проверь, что изменение было намеренным.
