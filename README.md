# AutoFMShift (Выбор FM адаптера в авто)

Веб-приложение для расчета оптимального сдвига частот (FM-адаптера) для автомобильных магнитол с нестандартным диапазоном частот (например, JDM).

## 📻 Проблематика

Владельцы автомобилей, привезенных из Японии (JDM — Japanese Domestic Market) или США, часто сталкиваются с проблемой прослушивания местного FM-радио. 

* **Стандарт РФ/Европа:** 87.5 – 108.0 МГц.
* **Япония (до 2014):** 76.0 – 90.0 МГц.
* **Япония (Wide FM):** 76.0 – 95.0 МГц.
* **Япония (JDM 78-99):** 78.0 – 99.0 МГц (некоторые специфические магнитолы).
* **США:** 87.9 – 107.9 МГц (только нечетные частоты).

Из-за этого японская магнитола физически не может принимать российские радиостанции на частотах выше 90 (или 95) МГц, которых в крупных городах подавляющее большинство.

**Решение:** Использование специального FM-адаптера ( frequency shifter / конвертера ), который врезается в антенный провод. Он аппаратно вычитает из частоты станции определенный сдвиг (например, 10, 12 или 20 МГц), позволяя станции "попасть" в диапазон магнитолы. 

**Сложность:** В разных городах разные частотные сетки. Если взять случайный адаптер, часть станций может всё равно не попасть в диапазон (или уйти ниже 76 МГц). 

**Цель приложения:** Автоматически спарсить частоты всех станций выбранного города, проанализировать доступные на рынке сдвиги адаптеров и подсветить те, которые позволяют покрыть 100% станций, а также выбрать "лучший" (кратный 10 для простоты вычисления в уме).

## ✨ Возможности

* **Парсинг данных:** Загрузка актуальных частот и названий станций для городов России.
* **Шаблоны ГУ:** Предустановленные диапазоны для разных рынков (РФ, JDM, USA) с возможностью ручного ввода.
* **Умный расчет адаптеров:** 
  * 🟢 Зеленый — лучший сдвиг (покрывает все станции и кратен 10).
  * ⚪ Белый — покрывает 100% станций.
  * 🟡🔴 От желтого к красному — покрывает только часть станций (градиент зависит от процента покрытия).
  * 🩷 Розовый — станции недоступны.
* **Таблица частот:** Наглядно показывает, на какой частоте станцию нужно искать на магнитоле после установки адаптера.
* **GeoIP:** Автоопределение города пользователя при первом заходе.
* **Шаринг и LocalStorage:** Сохранение состояния в URL и локально для быстрого доступа.

## 🛠 Технический стек

Проект написан на чистом **HTML5**, **CSS3** и **Vanilla JS (ES6+)** без использования фреймворков, сборщиков (Webpack/Vite) и сторонних зависимостей. 

* **CSS:** Использование CSS Variables для поддержки светлой и темной темы (автовыбор через `prefers-color-scheme`), Flexbox/Grid для адаптивной верстки.
* **JS:** Асинхронные запросы (Fetch API), парсинг HTML через DOMParser, работа с LocalStorage и History API.
* Архитектура представляет собой простой одностраничник (SPA) без роутинга, обновляющий UI через функцию `render()`.

## 🌐 API

Приложение использует открытые API:

1. **Radiopedia (Fandom API)**
   * URL: `https://radiopedia.fandom.com/ru/api.php`
   * Метод: `GET` (`action=parse`, `prop=text`)
   * Использование: Получение HTML-кода страниц со списком городов и таблицами частот радиостанций. Данные парсятся прямо из HTML-таблиц на стороне клиента.
2. **GeoJS**
   * URL: `https://get.geojs.io/v1/ip/geo.json`
   * Метод: `GET`
   * Использование: Определение города пользователя по IP-адресу для первичной настройки.

## 🚀 Запуск

Так как проект не имеет зависимостей и сборки, достаточно просто открыть `index.html` в браузере. 

Или запустить локальный сервер (например, через Live Server в VS Code или `python -m http.server`) для корректной работы GeoIP и API запросов (избегание CORS-проблем в некоторых браузерах при открытии через `file://`).
