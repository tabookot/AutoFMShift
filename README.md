Веб-приложение для расчета оптимального сдвига частот (FM-адаптера) для автомобильных магнитол с нестандартным диапазоном частот (например, JDM).

## 📻 Проблемы?

Владельцы автомобилей, привезенных в РФ из Японии (JDM) или других регионов, часто сталкиваются с проблемой прослушивания местного FM-радио. 

* **Стандарт РФ/Европа:** 87.5 – 108.0 МГц.
* **Япония (до 2014):** 76.0 – 90.0 МГц.
* **Япония (Wide FM):** 76.0 – 95.0 МГц.
* **США:** 87.9 – 107.9 МГц (только нечетные).
* **OIRT / СССР / Восточная Европа:** 65.9 – 74.0 МГц (для ретро-консерваторов).

Из-за этого родная магнитола физически не может принимать российские радиостанции на частотах выше 90 (или 95) МГц, которых в крупных городах подавляющее большинство.

**Решение:** Использование FM-адаптера (frequency shifter), который врезается в антенный провод. Он аппаратно вычитает из частоты станции определенный сдвиг (например, 12 или 20 МГц), позволяя станции "попасть" в диапазон магнитолы. 

**Сложность:** В разных городах разные частотные сетки. Если взять случайный адаптер, часть станций может всё равно не попасть в диапазон (или уйти ниже 76 МГц). 

**Цель приложения:** Показать частоты всех станций выбранного города, доступные на рынке сдвиги адаптеров и подсветить те, которые позволяют покрыть до 100% станций, а также выбрать лучший.

## ✨ Что умеет

* **Списки FM станций городов России:** Загрузка актуальных частот и названий станций для городов России с [Radiopedia Fandom](https://radiopedia.fandom.com/ru/). Если этот сайт упал или поменял вёрстку - приложение перестанет работать - авторы никак не связаны, финита ля комедия :)
* **Шаблоны ГУ:** Предустановленные диапазоны частот FM для разных авто-рынков (РФ, JDM, USA, OIRT) с возможностью ручного ввода.
* **Расчет покрытия местных FM частот адаптеров:** 
  * 🟢 **Зеленый** — лучший сдвиг (покрывает все станции и по возможности кратен 10).
  * ⚪ **Белый** — покрывает 100% станций.
  * 🟡🔴 **От желтого к красному** — покрывает только часть станций (градиент зависит от процента покрытия).
  * 🩷 **Розовый** — станции недоступны.
* **🔧 Расширенный режим настроек ГУ:**
  * Включается кнопкой с гаечным ключом. Позволяет указать количество бэндов и кнопок сохраненных станций в магнитоле.
  * **Статусы станций:** Кликайте по иконкам в таблице, чтобы отмечать избранное (♥), интересное (★) или мусор (✖ — полностью исключается из экспорта).
  * **Номера кнопок:** Назначайте станциям номера кнопок (1, 2 или 1.1, 1.2) через выпадающий список. Система запоминает абсолютные индексы, позволяя менять конфигурацию бэндов на лету без потери привязок для того, чтобы настроить примерно одинаково магнитолы нескольких машин.
* **📱 Адаптивность и тач-UI:** На сенсорных экранах поля ввода поддерживают жест свайпа вверх/вниз прямо по полю для смены числовых значений, на ПК - колесиком мышки.
* **Экспорт данных:**
  * **PNG:** Растровая картинка для просмотра с экрана устройства.
  * **PDF:** Текстовая таблица для просмотра, копирования и печати.
  * **XLSX:** Формат для правки и печати на 1 лист А4 ч/б принтера.
* **Инструкция настройки кнопок:** Список частот в экспортных файлах по порядку с номерами кнопок для быстрой настройки магнитолы.
* **GeoIP:** Автоопределение города пользователя по IP при первом заходе или по кнопке.
* **🔗 Поделиться ссылкой:** URL содержит город, диапазон частот ГУ, все ваши пометки (статусы и номера кнопок), закодированные в URL.

## 🛠 Для ботанов

Проект написан на чистом **HTML5**, **CSS3** и **Vanilla JS (ES6+)** с GLM 5.2. Никаких React-ов и сборщиков, только хардкор - работает без регистраций и бэкэнда.

* **CSS:** Использование CSS Variables для поддержки светлой и темной темы (автовыбор через `prefers-color-scheme`), Flexbox/Grid для адаптивной верстки, медиазапросы для тач-устройств.
* **JS:** Асинхронные запросы (Fetch API), парсинг HTML через DOMParser, работа с LocalStorage и History API.
* **Библиотеки:**
  * [`jsPDF`](https://github.com/parallax/jsPDF) + `jspdf-autotable` — генерация PDF для просмотра и печати.
  * [`xlsx-js-style`](https://github.com/lennonn/xlsx-js-style) — генерация стилизованных Excel-файлов для правки и печати на ч/б принтере.
* Архитектура представляет собой простой одностраничник (SPA) без роутинга, обновляющий UI через функцию `render()`.

## 🌐 Кого знает

Приложение использует открытые API:

1. **Radiopedia (Fandom API)**
   * URL: `https://radiopedia.fandom.com/ru/api.php`
   * Метод: `GET` (`action=parse`, `prop=text`)
   * Использование: Получение HTML-кода страниц со списком городов и таблицами частот радиостанций.
2. **GeoJS**
   * URL: `https://get.geojs.io/v1/ip/geo.json`
   * Метод: `GET`
   * Использование: Определение города пользователя по IP-адресу для первичной настройки.

## 🚀 Газуем

Так как проект не имеет зависимостей и сборки, достаточно просто открыть `index.html` в браузере, никаких установок, регистраций. Данные никуда не уходят и остаются в браузере пользователя. 

Айтишникам - можно запустить локальный сервер (например, через Live Server в VS Code или `python -m http.server`) для корректной работы GeoIP, шрифтов и API запросов (избегание CORS-проблем при открытии через `file://`).
