Веб-приложение для расчета оптимального сдвига частот (FM-адаптера) для автомобильных магнитол с нестандартным диапазоном частот (например, JDM).

## 📻 Проблемы?

Владельцы автомобилей, привезенных в РФ из Японии или других регионов, часто сталкиваются с проблемой прослушивания местного FM-радио на оригинальном головном устройстве (ГУ, магнитоле). 

* **Стандарт РФ/Европа:** 87.5 – 108.0 МГц.
* **Япония (до 2014):** 76.0 – 90.0 МГц.
* **Япония (Wide FM):** 76.0 – 95.0 МГц.
* **США:** 87.9 – 107.9 МГц (только нечетные).
* **OIRT / СССР / Восточная Европа:** 65.9 – 74.0 МГц (для ретро-консерваторов).

Из-за этого, например, родная японская магнитола физически не может принимать российские радиостанции на частотах выше 90 (или 95) МГц, которых в крупных городах подавляющее большинство.

**Решение:** Использование FM-адаптера (frequency shifter), который врезается в антенный провод. Он аппаратно вычитает из частоты станции определенный сдвиг (например, 12 или 20 МГц), позволяя станции "попасть" в диапазон магнитолы. 

**Сложность:** В разных городах разные частотные сетки. Если взять случайный адаптер, часть станций может всё равно не попасть в диапазон (или уйти ниже 76 МГц). 

**Цель приложения:** Показать частоты всех станций выбранного города, доступные на рынке сдвиги адаптеров и подсветить те, которые позволяют покрыть до 100% станций, а также выбрать лучший. Дополнительно - выбрать любимые станции и номера кнопок, чтобы распечатать для восстановления после сбросов или смены авто.

## ✨ Что почём

* **Списки FM станций городов России:** Загрузка актуальных частот и названий станций для городов России с [Radiopedia Fandom](https://radiopedia.fandom.com/ru/). Если этот сайт упал или поменял вёрстку - приложение перестанет подхватывать свежие данные, но сможет работать с данными в кэше или из сохраненного JSON :)
* **Шаблоны ГУ:** Предустановленные диапазоны частот FM магнитол для разных авто-рынков (РФ, JDM, USA, OIRT) с возможностью ручного ввода.
* **Расчет покрытия местных FM частот адаптеров:** 
  * 🟢 **Зеленый** — лучший сдвиг (покрывает все станции и по возможности кратен 10).
  * ⚪ **Белый** — покрывает 100% станций.
  * 🟡🔴 **От желтого к красному** — покрывает только часть станций (градиент зависит от процента покрытия).
  * 🩷 **Розовый** — станции недоступны.
* **🔧 Расширенный режим настроек ГУ:**
  * Включается кнопкой с гаечным ключом. Позволяет указать количество бэндов (наборов FM1, FM2, ...) и кнопок сохраненных станций в магнитоле.
  * **Статусы станций:** Кликайте по иконкам в таблице, чтобы отмечать избранное (♥), интересное (★) или мусор (✖ — полностью исключается из экспорта).
  * **Номера кнопок:** Назначайте станциям номера кнопок (1, 2 или 1.1, 1.2) через выпадающий список. Система запоминает абсолютные индексы, позволяя менять конфигурацию бэндов на лету без потери привязок для того, чтобы настроить примерно одинаково магнитолы нескольких машин.
* **📱 Адаптивность и тач-UI:** На сенсорных экранах поля ввода поддерживают жест свайпа вверх/вниз прямо по полю для смены числовых значений, на ПК - колесиком мышки.
* **Экспорт данных:**
  * **PNG:** Растровая картинка для просмотра с экрана устройства.
  * **PDF:** Текстовая таблица для просмотра, копирования и печати.
  * **XLSX:** Формат для правки и печати на 1 лист А4 ч/б принтера.
  * **JSON:** Формат для сохранения резервной копии настроек, позволит запустить приложение с сохраненными городами без интернета.  
* **Инструкция настройки кнопок:** Список частот в экспортных файлах - по порядку с номерами кнопок для быстрой настройки магнитолы.
* **GeoIP:** Автоопределение города пользователя по IP при первом заходе или по кнопке.
* **🔗 Поделиться ссылкой:** URL содержит один город, диапазон частот ГУ, все ваши пометки (статусы и номера кнопок), закодированные в URL.
* **🔄 Копирование настроек между городами:** Умное перенесение статусов (♥, ★, ✖) и номеров кнопок из одного города в другой. Встроенный алгоритм ищет умные совпадения по названиям станций.
* **💾 Экспорт / Импорт (JSON) и Офлайн-режим:** Резервное копирование настроек и списков станций для настроенных городов в один файл. Импорт (из окна справки) восстанавливает настройки и списки станций на других устройствах. Списки станций и городов кэшируются в LocalStorage, позволяя работать с приложением даже при падении API.
* **🛡️ Резервный кэш API (backup-api.json):** Этот файл служит «серверным» дублером: при падении основного API приложение автоматически переключается на резервный кэш, подтягивая недостающие города и сохраняя ваши настройки. Импорт бэкапа работает в режиме умного слияния, обновляя устаревшие данные без удаления пользовательских меток.

## 🛠 Ситуация

Проект на чистом **HTML5**, **CSS3** и **Vanilla JS (ES6+)** написан с GLM 5.2. Никаких React-ов и сборщиков, работает без регистраций бэкэнда и интернета.

* **CSS:** Использование CSS Variables для светлой и темной темы (автовыбор через `prefers-color-scheme`), Flexbox/Grid для адаптивной верстки, медиазапросы для тач-устройств.
* **JS:** Асинхронные запросы (Fetch API), парсинг HTML через DOMParser, работа с LocalStorage и History API. Библиотеки: GeoJS, jsPDF, exceljs. Внедрен собственный модуль (`fmuse.js`) для "умного" сопоставления названий станций при переносе настроек и синхронизации.
* Архитектура - простой одностраничник (SPA) без роутинга, обновляющий UI через функцию `render()`.

## 🌐 Кого знаем

Приложение использует открытые API и библиотеки:

1. [Radiopedia API](https://radiopedia.fandom.com/ru/api.php) Получение HTML-кода страниц со списком городов и таблицами частот радиостанций.
2. [GeoJS](https://get.geojs.io/v1/ip/geo.json) - местоположение пользователя по IP.
3. [jsPDF](https://github.com/parallax/jsPDF) — генерация PDF-файла.
4. [exceljs](https://github.com/exceljs/exceljs) — генерация Excel-файла.

## 🚀 Газуем

Так как проект не имеет зависимостей и сборки, достаточно просто скачать все файлы и открыть `index.html` в браузере, никаких установок, регистраций. Данные никуда не уходят и остаются в браузере пользователя. 

Можно запустить локальный сервер (например, через Live Server в VS Code или `python -m http.server`) для корректной работы GeoIP, шрифтов и API запросов (для избежания CORS-проблем при открытии через `file://`).
