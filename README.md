## 📻 В чем проблема?

Владельцы автомобилей, привезенных из Японии (JDM) или США, часто сталкиваются с проблемой прослушивания местного FM-радио. 

* **Стандарт РФ/Европа:** 87.5 – 108.0 МГц.
* **Япония (до 2014):** 76.0 – 90.0 МГц.
* **Япония (Wide FM):** 76.0 – 95.0 МГц.
* **США:** 87.9 – 107.9 МГц (только нечетные).
* **OIRT / СССР / Восточная Европа:** 65.9 – 74.0 МГц (для ретро-консерваторов).

Из-за этого японская магнитола физически не может принимать российские радиостанции на частотах выше 90 (или 95) МГц, которых в крупных городах подавляющее большинство.

**Решение:** Использование FM-адаптера (frequency shifter), который врезается в антенный провод. Он аппаратно вычитает из частоты станции определенный сдвиг (например, 10, 12 или 20 МГц), позволяя станции "попасть" в диапазон магнитолы. 

**Сложность:** В разных городах разные частотные сетки. Если взять случайный адаптер, часть станций может всё равно не попасть в диапазон (или уйти ниже 76 МГц). 

**Цель приложения:** Автоматически спарсить частоты всех станций выбранного города, проанализировать доступные на рынке сдвиги адаптеров и подсветить те, которые позволяют покрыть 100% станций, а также выбрать "лучший" (кратный 10 для простоты вычисления в уме).

## ✨ Возможности

* **Парсинг данных:** Загрузка актуальных частот и названий станций для городов России (Radiopedia API).
* **Шаблоны ГУ:** Предустановленные диапазоны для разных рынков (РФ, JDM, USA, OIRT) с возможностью ручного ввода границ.
* **Умный расчет адаптеров:** 
  * 🟢 **Зеленый** — лучший сдвиг (покрывает все станции и кратен 10).
  * ⚪ **Белый** — покрывает 100% станций.
  * 🟡🔴 **От желтого к красному** — покрывает только часть станций (градиент зависит от процента покрытия).
  * 🩷 **Розовый** — станции недоступны.
* **🔧 Расширенный режим настроек ГУ:**
  * Включается кнопкой с гаечным ключом. Позволяет указать количество бэндов и кнопок в магнитоле.
  * **Статусы станций:** Кликайте по иконкам в таблице, чтобы отмечать избранное (♥), интересное (★) или мусор (✖ — полностью исключается из экспорта).
  * **Номера кнопок:** Назначайте станциям номера кнопок (1, 2 или 1.1, 1.2) через удобный выпадающий список. Система запоминает абсолютные индексы, позволяя менять конфигурацию бэндов на лету без потери привязок.
* **📱 Адаптивность и тач-UI:** На сенсорных экранах поля ввода превращаются в "роллеры" (меняйте значения свайпом вверх/вниз прямо по полю). Кнопки статусов и чипы увеличены для удобного нажатия пальцем.
* **Экспорт данных:**
  * **PNG:** Растровая картинка. На мобильных генерируется в 1 колонку, на ПК — в две.
  * **PDF:** Настоящая векторная текстовая таблица (поддерживается выделение и копирование). Доступные частоты подсвечены зеленым, недоступные — красным.
  * **XLSX:** Формат для печати на А4. Включает колонку "Пометки" со статусами и номерами кнопок.
* **GeoIP:** Автоопределение города пользователя по IP при первом заходе.
* **🔗 Умный шаринг:** Ссылка теперь содержит не только город и диапазон, но и все ваши пометки (статусы и номера кнопок) для конкретного города, закодированные в URL.

## 🛠 Технический стек

Проект написан на чистом **HTML5**, **CSS3** и **Vanilla JS (ES6+)** с GLM 5.2. Никаких React-ов и сборщиков, только хардкор.

* **CSS:** Использование CSS Variables для поддержки светлой и темной темы (автовыбор через `prefers-color-scheme`), Flexbox/Grid для адаптивной верстки, медиазапросы для тач-устройств.
* **JS:** Асинхронные запросы (Fetch API), парсинг HTML через DOMParser, работа с LocalStorage и History API, кастомная реализация "роллеров" для `input[type=number]`.
* **Библиотеки:**
  * [`jsPDF`](https://github.com/parallax/jsPDF) + `jspdf-autotable` — генерация PDF с динамической подгрузкой TTF-шрифта для кириллицы.
  * [`xlsx-js-style`](https://github.com/lennonn/xlsx-js-style) — генерация стилизованных Excel-файлов с жестким указанием альбомной ориентации.
* Архитектура представляет собой простой одностраничник (SPA) без роутинга, обновляющий UI через функцию `render()`.

## 🌐 API

Приложение использует открытые API:

1. **Radiopedia (Fandom API)**
   * URL: `https://radiopedia.fandom.com/ru/api.php`
   * Метод: `GET` (`action=parse`, `prop=text`)
   * Использование: Получение HTML-кода страниц со списком городов и таблицами частот радиостанций. Данные парсятся прямо из HTML-таблиц на стороне клиента.
2. **GeoJS**
   * URL: `https://get.geojs.io/v1/ip/geo.json`
   * Метод: `GET`
   * Использование: Определение города пользователя по IP-адресу для первичной настройки.

## 🚀 Запуск

Так как проект не имеет зависимостей и сборки, достаточно просто открыть `index.html` в браузере. 

Или запустить локальный сервер (например, через Live Server в VS Code или `python -m http.server`) для корректной работы GeoIP, шрифтов и API запросов (избегание CORS-проблем при открытии через `file://`).

## 📁 Структура

* `index.html` — разметка UI.
* `style.css` — стили, темы, анимации, пасхалки.
* `app.js` — основная логика, парсинг, расчеты, экспорт и гостевой режим.
* `cities.js` — база координат городов для GeoIP радара.
* `img/` — логотип и засекреченный агент (наведитесь на правую часть панели адаптеров...).
